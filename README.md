# Bevan Omondi – Developer Portfolio

Plain HTML, CSS and JavaScript. No build step, no dependencies.

## Run it
Open `index.html` in a browser, or serve the folder with any static host.

## Structure
- `index.html`        page content and sections
- `css/style.css`     all styles (light and dark themes via CSS variables)
- `js/hero-chart.js`  animated candlestick background in the hero
- `js/site.js`        scroll progress bar, simulated EUR/USD, XAU/USD, Volatility 75 and Boom 1000 terminal, image lightbox
- `images/`           the trading screenshots used in the "Trading wins" section

## Notes
- The market terminal is a simulated animated demo, not live data.
- Fonts load from Google Fonts and fall back to system fonts offline.
